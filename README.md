What the project is

A static bookstore web app: HTML + CSS + vanilla JS, data in localStorage, no server and no build step. Requirements are in docs/REQUIREMENTS.md (R1–R20). Design is in docs/DESIGN.md, UML in docs/UML.md.

Run it: open Customer's/Login.html directly, or serve the folder:

cd "/home/arbcman/SA-1 Online bookstore"
python3 -m http.server 8000
# then visit http://localhost:8000/Customer's/Login.html
